# 猫门智能排版器

专为公众号创作者设计的排版工具。配合 Claude、Gemini 等 AI 使用，帮你完成：**文章排版 → 可视化编辑 → 一键复制到公众号 → 生成全套营销物料**。

---

## 快速开始

### 推荐：Next.js 版（功能最新）

需要 Node.js 18+。

```bash
git clone https://github.com/Farahcoco/Pandadoor-editor.git
cd Pandadoor-editor
npm install
npm run preview
```

浏览器打开：**http://localhost:3000**

### 备选：HTML 静态版（无需安装 Node）

```bash
npm run preview:html
```

浏览器打开：**http://localhost:8080/猫门智能排版器v9.html**

> 也可以直接双击 HTML 文件打开，但建议用本地服务器，避免浏览器安全限制。

## 怎么用（4 步）

```
第 1 步：选模式 + 选风格
    ↓
第 2 步：粘贴素材 → 复制提示词 → 发给 AI
    ↓
第 3 步：把 AI 返回的内容粘贴回来 → 自动解析 → 可视化编辑
    ↓
第 4 步：生成营销物料 + 复制排版 HTML 到公众号
```

### 第 1 步：选择创作模式

| 模式 | 你手里有什么 | AI 帮你做什么 |
|------|-------------|--------------|
| **A · 已有文章** | 写好的文章 | 优化排版、提炼金句、加配图建议 |
| **B · 主题创作** | 一个主题或想法 | 从零写一篇完整文章 |
| **C · 长素材提炼** | 逐字稿、播客文字稿、课程笔记 | 提炼成精华文章 |
| **D · 素材整合** | 多个碎片素材 | 整合成一篇原创文章 |

模式 B/C/D 还可以选择写作风格（猫门、柠檬心理、治愈系、硬核干货等）和文章长度。

### 第 2 步：生成提示词

1. 在输入框粘贴你的素材
2. 工具会自动生成一段提示词
3. 点击复制，粘贴到 AI 对话框（推荐 [Claude](https://claude.ai) 或 [Gemini](https://gemini.google.com)）
4. 等 AI 返回排版好的文章

### 第 3 步：编辑排版

1. 把 AI 返回的内容粘贴到编辑器
2. 工具会自动识别段落、金句、标题、笔记卡、图片等区块
3. 你可以：
   - 调整每个区块的类型和样式
   - 切换配色方案（20+ 种，含莫兰迪、森绿、多巴胺等）
   - 实时预览公众号效果（右侧手机预览）
   - 添加/删除/排序区块
4. 满意后，复制 HTML 粘贴到公众号编辑器

### 第 4 步：生成营销物料

一键生成全套推广文案，包括：

- 朋友圈文案（作者版 / 转发版）
- 小红书文案 + 标题备选
- 社群转发话术、私聊推荐话术
- 文章标题备选（8 个爆款风格）
- 目标人群画像
- 金句卡片文案
- 短视频口播文案
- SEO 关键词

## 支持的排版区块

| 区块类型 | 说明 |
|---------|------|
| 段落 | 普通正文 |
| 强调 | 加粗高亮的关键句 |

| 分割线 | 爪印 / 极简 / 星星 三种样式 |

## 项目结构

```
maomen-editor/
├── pages/
│   └── index.js              ← Next.js 主程序（最新版，推荐开发这个）
├── styles/
│   └── globals.css           ← 全局样式
├── public/
│   └── v9-fix.js             ← HTML 版核心逻辑
├── 猫门智能排版器v9.html        ← HTML 静态最新版
├── 猫门智能排版器v9-fix.html    ← HTML 修复版
├── index.html                  ← 入口，自动跳转到 v9
├── package.json
└── README.md
```

**两个版本的区别：**

| | Next.js 版 | HTML 版 |
|--|-----------|---------|
| 入口 | `npm run preview` → localhost:3000 | 双击 HTML 或 `npm run preview:html` |
| 适合 | 日常使用和开发 | 快速分享、离线使用 |
| 功能 | 最新 | 略旧，但核心功能完整 |

## 技术说明

- **前端框架**：Next.js 14 + React 18
- **HTML 版**：纯 HTML + CSS + JavaScript，零依赖
- **无需后端**：所有逻辑在浏览器端运行，不存储你的文章内容
- **无需 API Key**：工具本身不调用 AI，提示词由你复制到 AI 工具中使用
